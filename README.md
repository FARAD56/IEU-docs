# IEU Performance and Attendance: documentation

Documentation for the IEU Performance and Attendance System, a platform for the Islamic Education Unit's basic schools (Primary 1 to JHS 3) that tracks academic performance and attendance, with approvals and an audit trail.

**Read it at https://farad56.github.io/IEU-docs/**

The application's source code is private; this repository holds only the documentation site, built with Jekyll and the Just the Docs theme.

By [Al-Waasiu Abubakari](https://farad56.github.io/).
