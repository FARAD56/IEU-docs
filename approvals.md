# Approvals and audit

Changes that affect a student's record or how they're graded don't happen directly. They're requested, reviewed and recorded.

## Approval requests

| Request | Raised for |
|---|---|
| Add student | Enrolling a new student |
| Edit student | Changing a student's details |
| Promote student | Moving one student up a level |
| Bulk promotion | Moving a whole class up at the end of the year |
| Transfer student | Moving a student to another school |
| Change grading scheme | Activating or changing a scheme |
| BECE clearance | Clearing a JHS 3 student for the Basic Education Certificate Examination |
| Leave request | A staff member's leave |

Each request is pending, approved or rejected. A rejected request can be edited and submitted again, and every step is kept in the request's history. Heads see a count of what's waiting for them. For promotions, the system can work out which students are eligible and which class they move into next.

## Audit log

Important actions are written to an audit log: who did it, what changed and when. Directors can filter the log, and it's scoped to their region, like everything else they see.
